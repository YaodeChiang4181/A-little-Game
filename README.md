# Best Strategy博弈 (3-Lane Parity Tactical Card Game) ⚔️

這是一款結合了「三路陣線博弈」、「戰術姿態盲選宣告」、「15張精準牌庫」、「中路倍率禁令」與「專業復古像素美學」的雙人策略卡牌對戰遊戲。
雙方各自配置 15 張由 1~4 級組成的對稱牌池，在 5 回合內進行高密度的排位賽局心理戰。

---

## 🎯 核心玩法與遊戲機制 (Gameplay)

### 1. 牌庫規模與每回合發牌 (Deck & Hand Management)
* **15 張精準對稱牌庫**：雙方各自擁有 15 張卡牌（Lv.1~4），打滿 5 回合剛好抽完，零重複抽取。
* **每回合發 3 張（必全出）**：每回合雙方各獲得 3 張手牌，決策核心聚焦於「如何精確指派到左翼、中路、右翼」與「戰術姿態盲選宣告」。

### 2. 戰場三路結構與中路禁令 (3-Lane Arena & Constraints)
每回合固定存在 3 個戰場：
* **Lane[0] (左翼陣線)**：積分倍率 `Multiplier = 1`，無特殊限制。
* **Lane[1] (中路核心)**：積分倍率 `Multiplier = 2`，附帶每回合輪替的**【戰場禁令 (Lane Constraint)】**：
  * **奇數通行令**：僅限奇數等級 (LV.1, LV.3) 卡牌生效；偶數卡牌戰力視為 0。
  * **偶數通行令**：僅限偶數等級 (LV.2, LV.4) 卡牌生效；奇數卡牌戰力視為 0。
  * **輕裝突入令**：限制 LV.3 以下進場；超重型 LV.4 戰力視為 0。
  * **精銳衝鋒令**：限制 LV.2 以上進場；輕裝 LV.1 戰力視為 0。
  * **破法封魔域**：僅限純白板卡牌生效；特性角進入戰力視為 0。
  * **自由開闊域**：無任何進場限制，全等級卡牌正常發揮 ×2 戰力。
* **Lane[2] (右翼陣線)**：積分倍率 `Multiplier = 1`，無特殊限制。

### 3. 卡牌屬性與特性梯隊 (Card Progression)
* **卡牌等級**：固定為整數 1 到 4 級。
* **特性梯隊**：
  * **LV.1~2 (戰術特性角)**：暗影斥候（側翼突襲）、游擊陷阱兵（牽制泥沼）、重裝鐵衛（不屈壁壘）、核心刺客（中路刺殺）。
  * **LV.3~4 (高戰力純白板)**：堅石主塔、攻城投石車、審判聖官、光輝大主教、王國女統領、黑曜帝王。

### 4. 單回合 5 階段狀態機流程 (Turn State Machine)
每一回合嚴格依序執行以下 5 個階段：
1. **Phase 1: 佈陣與姿態宣告 (Deployment & Declaration)**
   * **選牌佈陣**：將 3 張手牌分別指派至 Lane[0], Lane[1], Lane[2]，即時預估己方戰力。
   * **姿態宣告 (盲選)**：
     * **[ 蓄力攻擊 ]**：代表強化蓄勢。本回合勝出時自身 `ATK += 1`（可跨回合無限累積）。
     * **[快速進攻]**：代表致命出鞘。本回合勝出時造成等於當前 ATK 的傷害，命中後 `ATK 重置回 1`。
2. **Phase 2: 開牌與特性結算 (Reveal & Trait Resolution)**
   * 同步翻開雙方 6 張卡牌與姿態宣告。
   * 檢核中路禁令（違規者戰力歸 0）並觸發卡牌特性，計算最終有效戰力 (effective_level)。
3. **Phase 3: 場地積分加總與勝負判定 (Score Calculation)**
   * 雙方各自計算總戰力：$\text{Total\_Score} = \sum_{i=0}^{2} (\text{effective\_level}_i \times \text{Multiplier}_i)$。
   * 比對分數：總分高者為本回合勝者 (Winner)；平局則為 Tie。
4. **Phase 4: 勝者行為執行 (Winner Action Execution)**
   * 僅有勝者可發動其宣告的戰術姿態（敗者無效果；平局雙方姿態皆作廢）：
     * 若宣告 ODD ➔ `Winner.ATK += 1`。
     * 若宣告 EVEN ➔ `Loser.HP -= Winner.ATK` 且 `Winner.ATK = 1`。
5. **Phase 5: 回合結束與終局判定 (End of Round Check)**
   * 即時擊殺：任一方 HP <= 0 立即分出勝負。
   * 第 5 回合上限裁決：比生命值高低 ➔ 比第 5 回合總積分 ➔ 比 5 回合累積總戰力 ➔ 平局 (Draw)。

### 5. 確定性平衡模擬器 (Deterministic Testing)
* 系統內建蒙地卡羅確定性模擬器 (`src/game/simulator.ts`)。
* 支援輸入固定隨機種子 (Seed) 或手牌序列，可於 DevTools 控制台直接呼叫 `__PARITY_SIMULATOR__.run(1000)` 驗證 1~4 級卡牌在 $1 \times 2 \times 1$ 倍率下的數值平衡。

### 6. 各遊戲模式共用規則 (Shared Rules Across Modes)
* **戰術對決**：雙方各使用一副 15 張標準牌組，每回合發 3 張，最多 5 回合；依本頁列出的中路禁令、卡牌特性與姿態結算。
* **一命通關**：每層戰鬥沿用相同的 15 張牌組、3 張手牌、三路倍率、中路禁令、姿態、特性與五回合裁決。五層敵方生命值、玩家跨層生命、營地選擇、積分及排行榜是此模式的額外進程規則。
* **雲端連機**：房主負責權威結算；雙方各自使用 15 張牌組、每回合盲選姿態並提交 3 張佈陣，規則與戰術對決相同。
* 各路戰報分別顯示雙方「有效戰力 × 路線倍率 = 該路得分」。同基礎等級卡牌若特性不同，有效戰力可能不同；特性生效時會在戰報列出，不以雙方等級差直接代替任何一方的得分。

## 🤖 智能 AI 對手 (Smart AI Agent)

AI 引擎採用二階賽局樹模擬：
* **三路排位組合運算**：遍歷 $3! = 6$ 種出牌排列，自動規避中路禁令懲罰，尋求期望總分最大化。
* **姿態博弈評估**：
  * **斬殺判斷**：若當前 `AI.ATK >= Player.HP`，高達 85% 機率宣告 `EVEN` 嘗試致命一擊。
  * **危機警戒**：自身殘血時提高出刀意願或防禦混淆。
  * **蓄力誘惑**：前期或 ATK=1 時優先宣告 `ODD` 積蓄後續威懾力。
  * **賽局雜訊**：維持 15%~25% 不可預測性，防止被高階玩家看穿。

## 💻 專案架構與技術棧 (Tech Stack)

全面採用純客戶端現代化架構，**徹底告別後端冷啟動延遲與免費用量限制，點開網頁 0.1 秒秒開秒玩！**

* **核心技術**：React 18 + Vite + TypeScript
* **架構模組**：
  * `src/game/types.ts`：通用角色、特性鉤子與戰鬥上下文型別。
  * `src/game/registry/characters.ts`：模組化像素角色註冊庫（支援自由擴充）。
  * `src/game/registry/terrains.ts`：動態戰場環境庫。
  * `src/game/engine.ts`：全特性與動態環境支援的戰鬥結算引擎。
  * `src/game/aiAgent.ts`：特性感知與環境適應型 AI 策略決策器。
  * `src/game/gameService.ts`：對局生命週期與狀態管理。
  * `src/game/soundManager.ts`：純前端 Web Audio 8-Bit 晶片音樂與戰鬥音效合成引擎（零外部流量依賴、100% 免費版權）。
  * `src/components/SettingsModal.tsx`：音效與背景音樂設定面板（支援獨立開關、音量滑桿與多首輕快戰鬥曲目切換）。
  * `src/game/towerEngine.ts`：奇偶試煉 (Tower Run) 刷塔進程（樓層首領、血量跨層繼承、營地、分數與本地排行榜）；每場戰鬥共用標準三路規則。
  * `src/game/towerCardGenerator.ts`：HTML5 Canvas 8-Bit 像素戰報卡生成器（純前端繪製可分享之戰報海報）。
  * `src/components/TowerView.tsx`：獨立刷塔試煉模式主窗口（層級戰況、專屬 HUD、修整營地與 Boss 決戰）。
  * `src/components/TowerResultModal.tsx`：試煉結算、歷史 Top 10 榮譽榜與戰報海報複製/下載彈窗。
  * `src/game/online/types.ts`：雲端對戰網路通訊協定型別（交握、回合同步、佈署廣播與心跳監控）。
  * `src/game/online/networkManager.ts`：基於 PeerJS WebRTC DataChannel 之純前端免伺服器 P2P 雲端連線管理器（0 後端成本、10~30ms 極致延遲）。
  * `src/components/OnlineLobbyModal.tsx`：雲端連機大廳（支援 6 位數房間代碼創建、邀請網址一鍵複製、雷達波紋掃描等待與快速加入）。
  * `src/components/OnlineMatchView.tsx`：雲端即時雙人交鋒（雙方 15 張牌組、每回合 3 張與姿態盲選、同步逐格結算、共用三路引擎、再戰與斷線防護）。
  * `src/game/economy/wallet.ts`：本地永久錢包與軍備陣容管理（支援 localStorage 金幣持久化、已徵召特職棋手庫存、出征卡組 6 槽位自由裝備與自訂立繪 Base64 快照）。
  * `src/components/ShopModal.tsx`：軍需商城模態窗口（支援 6 位全新西洋特職棋手招募、8-Bit 像素金幣音效與餘額即時扣除）。
  * `src/components/DeckBuilderModal.tsx`：軍備庫陣容編成與像素立繪上傳工坊（支援 1~6 階棋手自由替換出征、直接選取本機像素圖 PNG/GIF/WebP 即時替換卡面立繪，純前端 0 後端圖床依賴）。
  * `src/game/registry/CUSTOM_CHARACTERS_GUIDE.md`：開發者自訂角色與全新效果設定開發指南（包含 4 大生命週期鉤子、戰力修正與環境聯動完整教學）。
* **部署支援**：**Vercel**（官方推薦與正式部署環境，Root Directory: `frontend`，輸出目錄: `dist`，建置指令: `tsc && vite build`）、GitHub Pages 等靜態託管平台。

## ☁️ Vercel 部署設定指南 (Vercel Deployment Guide)

本專案已建立完整之 Vercel 部署與單頁應用 (SPA) 支援配置：
1. **Root Directory (根目錄設定)**：在 Vercel 專案設定中將 **Root Directory** 設定為 `frontend`。
2. **Framework Preset**：選擇 `Vite`。
3. **Build Command (建置指令)**：`tsc && vite build`（預設觸發嚴格 TypeScript 型別檢查）。
4. **Output Directory (輸出目錄)**：`dist`。
5. **SPA 路由配置**：`frontend/vercel.json` 內建重定向規則 (`rewrites: [ { source: "/(.*)", destination: "/index.html" } ]`)，保障網頁重新整理與深層路徑存取不發生 404。
